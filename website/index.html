StageAble reads your Ableton arrangement, builds a live timeline of songs, sections, lyrics, and chords, then streams everything to browser clients over WebSocket. No Max for Live required.

What it does

StageAble connects to Ableton Live through a bundled control surface bridge. It scans your arrangement for specially-named tracks — SONGS, SECTIONS, LYRICS, CHORDS, and CONTROL — and builds a deterministic timeline that follows the playhead in real time.

During a show, every phone, tablet, and laptop on your network sees the same live display: current song, section, chord symbols, and lyrics. One device can control transport while others stay locked as read-only displays for band members.

Setlist management lets you reorder songs, configure auto-cue between tracks, and jump to any song via Ableton cue points. Rehearsal mode supports looping sections for practice without touching the arrangement.

Live Display

  • ↔ Sliding animations when sections, chords, or lyrics change mid-song
  • ⛶ Fullscreen performance mode for stage displays

Transport & Navigation

  • ▶ Play, stop, previous, and next song controls from any browser client
  • ⌨ Keyboard shortcuts — Space for play/stop, arrow keys for prev/next song
  • 📍 Song navigation via named Ableton cue points
  • ⏹ Automatic STOP-event playback control — no Max for Live required
  • 🔒 Lock/unlock controls so only one device can drive transport

Setlist & Rehearsal

  • 📋 Persistent setlist management with drag-and-drop reordering
  • ⏭ Auto-cue between songs with configurable countdown
  • 🔁 Rehearsal mode — play single sections or loop contiguous ranges
  • 🔄 Re-scan arrangement after edits in Ableton

Mixer & Multi-Client

  • 🎚 Mixer tab for tracks prefixed with [MIX] — toggle Active/Inactive during a show
  • 💾 Save and load mixer presets for different songs or venues
  • 📱 Multi-client web UI — phones, tablets, and laptops stay in sync over WebSocket
  • 🔌 Auto-reconnects to Ableton if the connection drops

  • 🪟 Windows system tray app with the same feature set
  • ⬆ Built-in update checker with appcast support

Documentation

1. Install StageAble

  1. Download and install Download StageAble for Mac or Windows, or build from source. Unzip and move the app to Applications (Mac) or a folder of your choice (Windows).
  2. Launch the app Start StageAble from the menu bar (Mac) or system tray (Windows). No activation or sign-up required.

2. Install the Ableton Bridge

  1. Open Ableton Live Launch Ableton Live at least once before installing the bridge.
  2. Install from StageAble In the StageAble menu: Install Ableton Bridge… Then restart Ableton Live.
  3. Enable the control surface In Ableton: Preferences → Link / Tempo / MIDI → Control Surface → select StageAble.

3. Prepare your Ableton arrangement

Create these tracks in Arrangement View (names are case-insensitive):

Track Purpose
SONGS One clip per song; clip name = song title. Songs must not overlap.
SECTIONS Structural markers — Intro, Verse, Chorus, etc.
LYRICS Lyric lines; overlapping clips are allowed.
CHORDS Chord symbols shown verbatim (e.g. Am7, F | Bb).
CONTROL Clips named STOP auto-stop transport at song endings.
[MIX] … Any track starting with [MIX] appears in the Mixer tab.

Place a named cue point at each song's jump position — the cue point name must match the SONGS clip name exactly.

4. Connect phones and tablets

  1. Note the LAN address Check the address shown in the StageAble menu bar, e.g. 192.168.1.10:8000.
  2. Open in a browser On each device, open that URL. All clients stay in sync automatically.
  3. Unlock controls Tap the lock icon on one device if you need transport control. Other devices can stay locked as read-only displays.

After downloading

  1. Unzip and install Mac: move StageAble.app to Applications. Windows: unzip to a folder of your choice.
  2. Launch the app Open StageAble from Applications (Mac) or your install folder (Windows).
  3. Install the Ableton bridge From the menu bar (Mac) or system tray (Windows): Install Ableton Bridge… Then enable StageAble under Control Surface in Ableton preferences.
  4. Open the web UI Note the LAN address shown in the menu, then open it on a phone or tablet. See the Guides for full setup steps.
