What it does

StageAble connects to Ableton Live through a bundled control surface bridge. It scans your arrangement for specially-named tracks — SONGS, SECTIONS, LYRICS, CHORDS, and CONTROL — and builds a deterministic timeline that follows the playhead in real time.

During a show, every phone, tablet, and laptop on your network sees the same live display: current song, section, chord symbols, and lyrics. One device can control transport while others stay locked as read-only displays for band members.

Setlist management lets you reorder songs, configure auto-cue between tracks, and jump to any song via Ableton cue points. Rehearsal mode supports looping sections for practice without touching the arrangement.

Documentation

1. Install StageAble

  1. Download and install Download StageAble for Mac or Windows (free trial — no key needed). Unzip and move the app to Applications (Mac) or a folder of your choice (Windows).
  2. Activate your license Launch StageAble and enter your license key via the menu bar (Mac) or system tray (Windows): Activate License…

2. Install the Ableton Bridge

  1. Open Ableton Live Launch Ableton Live at least once before installing the bridge.
  2. Install from StageAble In the StageAble menu: Install Ableton Bridge… Then restart Ableton Live.
  3. Enable the control surface In Ableton: Preferences → Link / Tempo / MIDI → Control Surface → select StageAble.

3. Prepare your Ableton arrangement

Create these tracks in Arrangement View (names are case-insensitive):

Track Purpose
SONGS One clip per song; clip name = song title. Songs must not overlap.
SECTIONS Structural markers — Intro, Verse, Chorus, etc.
LYRICS Lyric lines; overlapping clips are allowed.
CHORDS Chord symbols shown verbatim (e.g. Am7, F | Bb).
CONTROL Clips named STOP auto-stop transport at song endings.
[MIX] … Any track starting with [MIX] appears in the Mixer tab.

Place a named cue point at each song's jump position — the cue point name must match the SONGS clip name exactly.

4. Connect phones and tablets

  1. Note the LAN address Check the address shown in the StageAble menu bar, e.g. 192.168.1.10:8000.
  2. Open in a browser On each device, open that URL. All clients stay in sync automatically.
  3. Unlock controls Tap the lock icon on one device if you need transport control. Other devices can stay locked as read-only displays.

5. Trial mode

Without a license key, StageAble runs in trial mode for 15 minutes per session. Activate a key from the menu to remove the limit.
