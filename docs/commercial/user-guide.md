# StageAble — User Guide

Buyer-oriented setup guide for live performance with Ableton Live.

## 1. Install StageAble

1. Download `StageAble-macOS.zip` from your purchase email.
2. Unzip and move `StageAble.app` to Applications.
3. Launch StageAble from Applications (first launch shows the license agreement).
4. Activate your license key via the menu bar: **Activate License…**

## 2. Install the Ableton Bridge

1. Open Ableton Live at least once.
2. In StageAble menu bar: **Install Ableton Bridge…**
3. Restart Ableton Live.
4. Preferences → Link / Tempo / MIDI → Control Surface → select **StageAble**.

## 3. Prepare your Ableton arrangement

Create these tracks (names are case-insensitive):

| Track | Purpose |
|-------|---------|
| SONGS | One clip per song; clip name = song title |
| SECTIONS | Section markers |
| LYRICS | Lyrics lines |
| CHORDS | Chord symbols |
| CONTROL | STOP clips for auto-stop |

## 4. Connect phones and tablets

1. Note the address shown in the StageAble menu bar (e.g. `192.168.1.10:8000`).
2. On each device, open that URL in a browser.
3. Unlock controls on one device if you need transport control.

## 5. Managing projects

StageAble stores one record per Ableton Live set you scan. Setlists and mixer presets belong to a specific project.

1. Unlock controls on one device.
2. Open the **Admin** tab, then **Projects**.
3. Review stored projects, including the active project shown in the header.
4. **Rename** updates StageAble's stored path when you moved or renamed the `.als` file on disk. This keeps setlists and mixer presets linked; it does not move or rename the file in Finder or Explorer.
5. **Delete** removes the cached scan, setlists, and mixer presets for a project you no longer need.
6. After opening a moved project in Ableton, use **Admin → Rescan** so the arrangement cache stays current.

## 6. Trial mode

Without a license key, StageAble runs in **trial mode** for 15 minutes per session. Activate a key from the menu bar to remove the limit.
