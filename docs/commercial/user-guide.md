# RemoteAble — User Guide

Buyer-oriented setup guide for live performance with Ableton Live.

## 1. Install RemoteAble

1. Download `RemoteAble-macOS.zip` from your purchase email.
2. Unzip and move `RemoteAble.app` to Applications.
3. Launch RemoteAble from Applications (first launch shows the license agreement).
4. Activate your license key via the menu bar: **Activate License…**

## 2. Install the Ableton Bridge

1. Open Ableton Live at least once.
2. In RemoteAble menu bar: **Install Ableton Bridge…**
3. Restart Ableton Live.
4. Preferences → Link / Tempo / MIDI → Control Surface → select **RemoteAble**.

## 3. Prepare your Ableton arrangement

Create these tracks (names are case-insensitive):

| Track | Purpose |
|-------|---------|
| SONGS | One clip per song; clip name = song title |
| SECTIONS | Section markers |
| LYRICS | Lyrics lines |
| CHORDS | Chord symbols |
| CONTROL | STOP clips for auto-stop |

## 4. Connect phones and tablets

1. Note the address shown in the RemoteAble menu bar (e.g. `192.168.1.10:8000`).
2. On each device, open that URL in a browser.
3. Unlock controls on one device if you need transport control.

## 5. Trial mode

Without a license key, RemoteAble runs in **trial mode** for 15 minutes per session. Activate a key from the menu bar to remove the limit.
